# React Native Fitness App

A fitness-focused mobile application built with **React Native**, designed to help users plan workouts, track training routines, and organize meals in one place. The project was developed as a practical learning project with an emphasis on real-world app structure, state management, and scalable code organization.

---

## 📱 Overview

The app allows users to structure their fitness routine by selecting exercises based on muscle groups, planning workouts through a calendar, and managing meals with macro and calorie tracking. The goal of the project was to simulate a real production-style mobile app while strengthening skills in frontend development, state management, and mobile workflows.

---

## ✨ Features

* **Exercise Library** – Browse exercises categorized by muscle groups
* **Workout Planning** – Plan and organize workouts using a built-in calendar
* **Meal Planner** – Track meals, calories, and macronutrients
* **Custom Workouts** – Add or adjust exercises to fit individual training needs
* **Progress-Oriented Structure** – Designed with long-term tracking in mind

---

## 🛠 Tech Stack

* **React Native** – Mobile application framework
* **Redux** – State management
* **Firebase** – Data storage and handling
* **JavaScript / TypeScript** – Application logic
* **Android Studio** – Emulator and development environment

---

## 🧱 Project Structure

The project is structured to resemble a real-world React Native application:

* **components/** – Reusable UI components
* **screens/** – Application screens and views
* **store/** – Redux state management logic
* **services/** – Firebase and data-related logic
* **assets/** – Static assets such as icons and images

This structure supports scalability and maintainability as the app grows.

---

## 🚀 Getting Started

### Prerequisites

* Node.js (LTS recommended)
* npm or yarn
* Android Studio (for Android emulator)
* React Native CLI environment set up

### Installation

```bash
npm install
```

### Running the App

```bash
npm start
```

Then run the app on an Android emulator or physical device using Android Studio.
